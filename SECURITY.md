# Security

Report suspected vulnerabilities privately to
[monnerat.gustavo@outlook.com](mailto:monnerat.gustavo@outlook.com), not in a public issue.
Include the mangapress version, operating system, command, impact, and a small synthetic
input or reproduction steps. Avoid sending manga pages or personal data.

Fixes target the latest release and current development branch. Older releases are not
maintained separately. This is a small volunteer project; there is no guaranteed response
or fix deadline. Please allow time to investigate before publishing exploit details.

For ordinary bugs and feature requests, use [GitHub Issues](https://github.com/gustavommcv/mangapress/issues).
